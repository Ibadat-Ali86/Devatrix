3. Form Architecture & Data Lifecycle

// Unique Tracking ID Generation Algorithm
const randomPin = Math.floor(1000 + Math.random() * 9000);
const trackingId = `DEV-INT-2026-${randomPin}`; // Careers: DEV-JOB-2026-${randomPin}

Data Persistence Workflow

  1. Client Submission: Candidate submits multipart form via fetch() with state spinners and validation.
  2. Server Processing (API Route):
    • Validates required inputs (Full Name, Email, WhatsApp, Track/Role).
    • Generates unique tracking ID (DEV-INT-2026-XXXX or DEV-JOB-2026-XXXX).
    • If a resume file is uploaded, writes securely to public/uploads/resumes/ with timestamped filename.
    • Appends application object into data/internship-applications.json or data/career-applications.json.
    • Invokes Google Sheets Webhook asynchronously in an isolated try-catch block to prevent webhook failures from blocking the user response.
    • Returns HTTP 200 with the tracking ID and timestamp.

2. Complete PostgreSQL Database Schema

Below is the complete production DDL schema optimized for Supabase / PostgreSQL:

-- 1. Core Users Table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    whatsapp VARCHAR(50) NOT NULL,
    role VARCHAR(50) DEFAULT 'APPLICANT' CHECK (role IN ('APPLICANT', 'INTERN', 'MENTOR', 'ADMIN')),
    github_username VARCHAR(100),
    avatar_url TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Cohort Definitions
CREATE TABLE cohorts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    code VARCHAR(50) UNIQUE NOT NULL, -- e.g. COHORT-2026-Q1
    title VARCHAR(100) NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    is_active BOOLEAN DEFAULT TRUE
);

-- 3. Cohort Enrollments
CREATE TABLE cohort_enrollments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    cohort_id UUID REFERENCES cohorts(id),
    user_id UUID REFERENCES users(id),
    track VARCHAR(100) NOT NULL,
    github_repo_url TEXT,
    mentor_id UUID REFERENCES users(id),
    is_completed BOOLEAN DEFAULT FALSE,
    earned_top_performer BOOLEAN DEFAULT FALSE,
    final_grade NUMERIC(5,2)
);

-- 4. 3-Phase Milestone Submissions
CREATE TABLE milestone_submissions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    enrollment_id UUID REFERENCES cohort_enrollments(id) ON DELETE CASCADE,
    phase_number INT CHECK (phase_number IN (1, 2, 3)),
    pull_request_url TEXT NOT NULL,
    live_demo_url TEXT,
    documentation_url TEXT,
    score NUMERIC(5,2),
    mentor_feedback TEXT,
    reviewed_by UUID REFERENCES users(id),
    reviewed_at TIMESTAMP WITH TIME ZONE
);

-- 5. Verified Credentials & Certificates
CREATE TABLE credentials (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    credential_id VARCHAR(50) UNIQUE NOT NULL, -- e.g. DEV-INT-2026-XXXX
    enrollment_id UUID REFERENCES cohort_enrollments(id),
    recipient_name VARCHAR(255) NOT NULL,
    track_title VARCHAR(100) NOT NULL,
    is_top_performer BOOLEAN DEFAULT FALSE,
    certificate_pdf_url TEXT NOT NULL,
    lor_pdf_url TEXT,
    qr_code_url TEXT NOT NULL,
    cryptographic_hash VARCHAR(64) NOT NULL
);
